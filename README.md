# 📻 Backbench Radio

> **A nostalgic web radio for the back row.** Curated slow indie, acoustic, and hip-hop beats with ambient sound mixing, dynamic moods, and an animated vinyl turntable.

---

## ✨ Features

- **4 Mood Themes**: 
  - 🌅 *Campus* — Warm morning acoustic vibes
  - 🌧️ *Rainy Night* — Moody indie & rainy night drive
  - 📚 *Classroom* — Cozy window bench melodies
  - 🎤 *Hip Hop & Desi Cypher* — Heavy 808s, rap & concert energy
- **Vinyl Turntable**: Realistic grooved vinyl disc with animated tonearm needle and ambient pulsing light.
- **Ambient Sound Mixer**: Layer background sounds (Rain, Fireplace, Wind, Cafe).
- **Sleep Timer**: Built-in countdown timer with auto-pause.
- **Keyboard Shortcuts**: Full hotkey support for play/pause, next/prev, volume, mute, and themes.
- **Responsive**: Optimized for both mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Library**: React 19, Lucide Icons
- **Analytics**: Vercel Analytics & Speed Insights

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vartiwa/backbench-radio.git
   cd backbench-radio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deployment

Easily deploy to **Vercel** or **Cloudflare Pages**:

```bash
npm run build
```
